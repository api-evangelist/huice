# Huice (慧策) — Wangdiantong Open Platform

> Huice (慧策) is a Chinese enterprise-software company whose flagship product, Wangdiantong (旺店通)
> ERP, is a tailor-made e-commerce management system covering orders, warehouse/inventory (WMS),
> goods, procurement, after-sales, and financial operations. Its public Open Platform exposes an HTTP
> API (openapi2) for third-party integrators, secured with a sid + appkey + timestamp + MD5 signature
> scheme, page_no/page_size pagination, and a code/message response envelope.

## APIs

- [Wangdiantong Open Platform API](https://open.wangdian.cn/qyb/open/apidoc): HTTP API (openapi2), base https://api.wangdian.cn/openapi2/ (sandbox https://sandbox.wangdian.cn/openapi2/). Named PHP methods across basics, goods, orders, after-sales, procurement, and inventory (e.g. trade_push.php, trade_query.php, goods_query.php, stock_query.php).
